# Abhijeet Kumar — Portfolio

Modern personal portfolio built with Next.js, TypeScript, CSS and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Customize

Edit `data/portfolio.ts` for profile, skills, experience, education and projects.

Replace `public/resume.pdf` with your resume and update the GitHub, LinkedIn and email values in `data/portfolio.ts`.

## Deploy

Push the repository to GitHub and import it into Vercel.
